# M3508I RS485 协议

本仓库包含 M3508I 电机 RS485 协议的 C 实现、RS485 转接板设计和 STM32 示例工程。

## 协议概览

| 项目 | 值 |
|---|---|
| 物理层 | RS485 半双工 |
| 串口格式 | 921600 baud，8 数据位，无校验，1 停止位 |
| 电机 ID | 0、1、2、3 |
| 下行控制帧 | 22 字节 |
| 上行回包 | 32 字节 |
| 角度分辨率 | 32768 count/机械圈 |

本文统一称控制板发送给电机的数据为“下行控制帧”，称电机发送给控制板的数据为“上行回包”。每个下行控制帧都会更新四个电机槽位。字节 7 选择本次发送上行回包的电机。

一次请求/应答通信由一个 22 字节下行控制帧和一个 32 字节上行回包组成。频率测试时，应答 ID 按 0、1、2、3 轮换发送。实测可靠上限是每秒 1333 次请求/应答事务，也就是每秒 1333 次广播；每秒 1334 次不可靠。四台电机完整轮询一次需要 4 次事务，因此完整轮询频率约为每秒 333.25 次。每台电机的回包频率约为 333.25 Hz，但每个控制帧仍会更新四个电机槽位。

## 下行控制帧

所有多字节数据均采用小端序。

| 偏移 | 长度 | 字段 | 描述 |
|---:|---:|---|---|
| 0..6 | 7 | 常量 | `55 16 00 9D A0 00 00` |
| 7 | 1 | 应答 ID | 取 0..3，指定回复的电机 |
| 8..9 | 2 | 速度槽 0 | 电机 0 |
| 10..11 | 2 | 速度槽 1 | 电机 1 |
| 12..13 | 2 | 速度槽 2 | 电机 2 |
| 14..15 | 2 | 速度槽 3 | 电机 3 |
| 16..19 | 4 | 常量 | `FF FF FF FF` |
| 20..21 | 2 | CRC16 | 覆盖字节 0..19，小端序 |

### 速度槽

速度槽是一个 16 位数，低 14 位是有符号速度编码。

高两位决定电机状态：

| bit15 | bit14 | 状态 |
|---:|---:|---|
| 0 | 0 | 使能 |
| 0 | 1 | 失能，不输出扭矩 |
| 1 | 0 | 使能；bit15 本身不是失能标志 |
| 1 | 1 | 使能 |

本项目实际使用的编码方式为：

```c
slot = (uint16_t)((16384 + (int)lroundf(speed_rpm * 8.191f)) % 16384 | !enable << 14);
```

已使用的速度范围为 -1000 至 +1000 rpm，对应端点编码为 `0x2001` 和 `0x1FFF`。`0x2000` 是有效的使能值，按有符号 14 位解码为 `-8192`。当 `enable` 为 false 时，程序通过 `!enable << 14` 设置 bit14，低 14 位仍然由 `speed_rpm` 计算得到。

## 上行回包

所有多字节数据均采用小端序。

| 偏移 | 长度 | 字段 | 描述 |
|---:|---:|---|---|
| 0..5 | 6 | 常量 | `55 20 00 1A A0 01` |
| 6 | 1 | 电机 ID | 回包电机，取 0..3 |
| 7 | 1 | 常量 | `00` |
| 8 | 1 | 可变字节 | 含义未知 |
| 9 | 1 | 母线电压 | `voltage_v = (byte9 + 3) / 4`，分辨率 0.25 V/count |
| 10..11 | 2 | 电流/扭矩原始值 | `int16_t` 有符号协议值 |
| 12..13 | 2 | 芯片内部温度原始值 | SPD1078 芯片内部温度传感器的值 |
| 14..15 | 2 | 实测转速 | 有符号值，1 rpm/count，逐帧存在噪声 |
| 16..17 | 2 | 控制槽回显 | 控制槽低 14 位，按有符号 14 位数解释 |
| 18..19 | 2 | 线圈温度原始值 | 贴在线圈上的温度传感器的值 |
| 20 | 1 | 状态 | `0x50` 使能，`0x90` 失能 |
| 21 | 1 | 常量 | `00` |
| 22..23 | 2 | 绝对角度 | 15 位计数，在 32767 后回绕到 0；32768 count/机械圈 |
| 24..25 | 2 | 序列号 | 每台电机独立计数，每帧加 1，`FFFF` 后回绕到 `0000` |
| 26..29 | 4 | 常量 | `00 00 00 00` |
| 30..31 | 2 | CRC16 | 覆盖字节 0..29，小端序 |

电流/扭矩字段是协议原始计数，不是安培值，也没有在本项目中定义扭矩换算比例。两个温度字段是传感器原始计数，本项目不定义温度换算公式。

根据角度计算转速时，对 32768 取模并进行有符号回绕：

```text
delta = signed_wrap(angle_new - angle_old, 32768)
rpm = delta * 60 / (32768 * elapsed_seconds)
```

角度计算的转速比实测转速字段平滑，适合用于速度环或位置环。

## CRC16

CRC 算法参数如下：

- 初值 `0x496C`
- 多项式 `0x1021`
- 每个输入字节先进行位反转
- 采用左移计算
- 最终 16 位结果进行位反转
- 在线路上按小端序存放

控制帧 CRC 覆盖前 20 字节，回包 CRC 覆盖前 30 字节。

## C API

`m3508i.h` 定义帧长度、角度分辨率、控制结构体、回包结构体和两个函数：

```c
void m3508i_build_frame(
    uint8_t (*out_frame)[M3508I_COMMAND_FRAME_SIZE],
    uint8_t responder_id,
    struct m3508i_cmd (*motor_cmd)[4]);

bool m3508i_parse_frame(
    struct m3508i_reply *out_reply,
    uint8_t (*in_frame)[M3508I_REPLY_FRAME_SIZE]);
```

使用示例：

```c
#include "m3508i.h"

struct m3508i_cmd motors[4] = {
    { .speed_rpm = 100.0f,  .enable = true  },
    { .speed_rpm = -50.0f,  .enable = true  },
    { .speed_rpm = 0.0f,    .enable = false },
    { .speed_rpm = 200.0f,  .enable = true  },
};
uint8_t tx[M3508I_COMMAND_FRAME_SIZE];
uint8_t rx[M3508I_REPLY_FRAME_SIZE];
struct m3508i_reply reply;

m3508i_build_frame(&tx, 0, &motors);
/* 通过 RS485 发送 22 字节，然后接收 32 字节。 */
if (m3508i_parse_frame(&reply, &rx)) {
    /* reply.motor_id、reply.angle_count、reply.sequence 等 */
}
```

`m3508i_parse_frame` 会校验回包 CRC，并填写 `struct m3508i_reply` 暴露的字段。需要电流或温度原始字段时，应同时保留完整的 32 字节回包。

## STM32 示例

`m3508i-test/` 使用 UART4，引脚如下：

| 引脚 | 功能 |
|---|---|
| PA0-WKUP | UART4_TX，连接 RS485 DI |
| PA1 | UART4_RX，连接 RS485 RO |
| PA2 | RS485 收发方向控制 |
| PA3..PA6 | 电机 0..3 指示灯，低电平点亮 |

示例程序发送完整控制帧，接收指定电机回包，并使用角度反馈循环依次控制电机 0 至 3。每台电机以 50 rpm 指令转动 2 圈。
