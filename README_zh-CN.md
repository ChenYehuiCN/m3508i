# M3508I RS485 协议

本仓库包含 M3508I 电机 RS485 协议的 C 实现、RS485 转接板设计和 STM32 示例工程。

## 协议概览

| 项目 | 值 |
|---|---|
| 物理层 | RS485 半双工 |
| 串口格式 | 921600 baud，8 数据位，无校验，1 停止位 |
| 电机 ID | 0、1、2、3 |
| 控制帧 | 22 字节 |
| 回包 | 32 字节 |
| 角度分辨率 | 32768 count/机械圈 |

每个控制帧都会更新四个电机槽位。字节 7 选择本次发送回包的电机。

完整轮询四台电机时，依次发送应答 ID 为 0、1、2、3 的四个控制帧。在当前 ESP32 固件、RS485 转接板和 921600 baud 配置下，实测可靠上限为每秒 1333 次完整轮询；每秒 1334 次不可靠。

## 控制帧

所有多字节数据均采用小端序。

| 偏移 | 长度 | 字段 | 值或含义 |
|---:|---:|---|---|
| 0..2 | 3 | 帧头 | `55 16 00` |
| 3 | 1 | 帧头 | `0x9D` |
| 4 | 1 | 帧头 | `0xA0` |
| 5..6 | 2 | 帧头 | `00 00` |
| 7 | 1 | 应答 ID | 取 0..3，指定回复的电机 |
| 8..9 | 2 | 速度槽 0 | 电机 0 |
| 10..11 | 2 | 速度槽 1 | 电机 1 |
| 12..13 | 2 | 速度槽 2 | 电机 2 |
| 14..15 | 2 | 速度槽 3 | 电机 3 |
| 16..19 | 4 | 固定字节 | `FF FF FF FF` |
| 20..21 | 2 | CRC16 | 覆盖字节 0..19，小端序 |

### 速度槽

速度槽是一个 16 位数，低 14 位是有符号速度编码：

```text
low14   = slot & 0x3FFF
signed  = low14 < 0x2000 ? low14 : low14 - 0x4000
p16_rpm = signed / 8.191
```

高两位决定电机状态：

| `slot & 0xC000` | 状态 |
|---:|---|
| `0x0000` | 使能 |
| `0x4000` | 失能，不输出扭矩 |
| `0x8000` 或 `0xC000` | 使能；bit15 本身不是失能标志 |

本项目使用的正常编码方式为：

```c
code = (0x4000 + round_away_from_zero(speed_rpm * 8.191)) % 0x4000;
slot = code | (enable ? 0x0000 : 0x4000);
```

已使用的速度范围为 -1000 至 +1000 rpm，对应端点编码为 `0x2001` 和 `0x1FFF`。`0x2000` 是有效的使能值，按有符号 14 位解码为 `-8192`。失能槽的低 14 位可以保留任意值；通常使用 `0x4000`。

## 回包

所有多字节数据均采用小端序。`p10`、`p12`、`p14`、`p16`、`p18` 表示对应字节偏移处的字段。

| 偏移 | 长度 | 字段 | 含义 |
|---:|---:|---|---|
| 0..2 | 3 | 帧头 | `55 20 00` |
| 3 | 1 | 常量 | `1A` |
| 4 | 1 | 常量 | `A0` |
| 5 | 1 | 常量 | `01` |
| 6 | 1 | 电机 ID | 回包电机，取 0..3 |
| 7 | 1 | 常量 | `00` |
| 8 | 1 | 可变字节 | 数值会变化，本项目不定义其协议含义 |
| 9 | 1 | 母线电压 | `voltage_v = (byte9 + 3) / 4`，分辨率 0.25 V/count |
| 10..11 | 2 | p10 | `int16_t` 有符号电流/扭矩原始值 |
| 12..13 | 2 | p12 | SPD1078 芯片内部温度传感器原始值 |
| 14..15 | 2 | p14 | `int16_t` 实测转速，约 1 rpm/count，逐帧存在噪声 |
| 16..17 | 2 | p16 | 控制槽低 14 位的回显，按上面的有符号 14 位规则解码 |
| 18..19 | 2 | p18 | 贴在线圈上的温度传感器原始值 |
| 20 | 1 | 状态 | `0x50` 使能，`0x90` 失能 |
| 21 | 1 | 常量 | `00` |
| 22..23 | 2 | 绝对角度 | 15 位计数，模 32768；32768 count/机械圈 |
| 24..25 | 2 | 序列号 | 每台电机独立计数，每帧加 1，`FFFF` 后回绕到 `0000` |
| 26..29 | 4 | 常量 | `00 00 00 00` |
| 30..31 | 2 | CRC16 | 覆盖字节 0..29，小端序 |

p10 是协议原始计数，不是安培值，也没有在本项目中定义扭矩换算比例。p12 和 p18 是温度传感器原始计数，本项目不定义温度换算公式。

根据角度计算转速时，对 32768 取模并进行有符号回绕：

```text
delta = signed_wrap(angle_new - angle_old, 32768)
rpm = delta * 60 / (32768 * elapsed_seconds)
```

角度计算的转速比 p14 平滑，适合用于速度环或位置环。

## CRC16

CRC 算法参数如下：

- 初值 `0x496C`
- 多项式 `0x1021`
- 每个输入字节先进行位反转
- 采用左移计算
- 最终 16 位结果进行位反转
- 在线路上按小端序存放

控制帧 CRC 覆盖前 20 字节，回包 CRC 覆盖前 30 字节。

## C API

`m3508i.h` 定义帧长度、角度分辨率、控制结构体、回包结构体和两个函数：

```c
void m3508i_build_frame(
    uint8_t (*out_frame)[M3508I_COMMAND_FRAME_SIZE],
    uint8_t responder_id,
    struct m3508i_cmd (*motor_cmd)[4]);

bool m3508i_parse_frame(
    struct m3508i_reply *out_reply,
    uint8_t (*in_frame)[M3508I_REPLY_FRAME_SIZE]);
```

使用示例：

```c
#include "m3508i.h"

struct m3508i_cmd motors[4] = {
    { .speed_rpm = 100.0f,  .enable = true  },
    { .speed_rpm = -50.0f,  .enable = true  },
    { .speed_rpm = 0.0f,    .enable = false },
    { .speed_rpm = 200.0f,  .enable = true  },
};
uint8_t tx[M3508I_COMMAND_FRAME_SIZE];
uint8_t rx[M3508I_REPLY_FRAME_SIZE];
struct m3508i_reply reply;

m3508i_build_frame(&tx, 0, &motors);
/* 通过 RS485 发送 22 字节，然后接收 32 字节。 */
if (m3508i_parse_frame(&reply, &rx)) {
    /* reply.motor_id、reply.angle_count、reply.sequence 等 */
}
```

`m3508i_parse_frame` 会校验回包 CRC，并填写 `struct m3508i_reply` 暴露的字段。需要 p10、p12、p18 等原始字段时，应同时保留完整的 32 字节回包。

## STM32 示例

`m3508i-test/` 使用 UART4，引脚如下：

| 引脚 | 功能 |
|---|---|
| PA0-WKUP | UART4_TX，连接 RS485 DI |
| PA1 | UART4_RX，连接 RS485 RO |
| PA2 | RS485 收发方向控制 |
| PA3..PA6 | 电机 0..3 指示灯，低电平点亮 |

示例程序发送完整控制帧，接收指定电机回包，并使用角度反馈循环依次控制电机 0 至 3。每台电机以 50 rpm 指令转动 2 圈。
